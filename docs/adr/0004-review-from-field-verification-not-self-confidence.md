# Review status comes from field verification, not model-reported confidence

Each extracted field is marked verified, unverified or failed by independent checks: the evidence span found verbatim in source text, arithmetic cross-checks, rule checks, and agreement between two reads, the second by a stronger model, for image Sources and for lines whose critical checks failed. A line is `needs_review` when a critical field (price, currency, pack size, UOM, ingredients/strength) fails, or is unverified on an image Source, or when the line is in a Conflict or carries a revision. Self-reported float confidence was dropped because verbalized LLM confidence is poorly calibrated. A categorical `stated / inferred / unclear` label is kept as an input to review reasons. We rejected "all image lines need review" because it makes the image path pointless; verified image lines can be auto-accepted.

## Consequences

- The eval measures flagging quality (share of wrong fields that were flagged) alongside review load (% lines `needs_review`, % fields flagged, flags on correct fields), so the policy can't win by flagging everything.
- Both image reads come from the same provider (see ADR-0005), so their errors are less independent than cross-family reads would be. On the sample, both reads gave one scanned unit price the same wrong value; only the line-total check caught it.
- Critical fields on an image line need arithmetic or second-read agreement to verify. A line with no line total and no second read always goes to review.
- An image has no source text, so its evidence span is the model's own transcription. A value that agrees with it confirms nothing and stays unverified. A value that contradicts it fails, as it would for a text Source. The eval found a scan read with thousands separators taken as decimal points: the spans said "41,400.00" and the values said 41. Quantity and line total were both off by the same factor, so the line-total check passed on two wrong numbers. A span with a single separator ("120,000") stays ambiguous and still accepts 120.
