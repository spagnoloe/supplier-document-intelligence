# The LLM extracts only stated values; code derives the rest

The extractor records prices exactly as the document states them: `unit_price` and/or `pack_price`, each only when stated, plus `pack_size`, `uom`, `discount_pct`, `price_tiers`, and line totals where present. Deterministic code derives the missing price, net-of-discount price, and USD conversion, and cross-checks stated values against each other (unit × pack size ≈ pack price; qty × unit × (1 − discount) ≈ line total). The original sketch had the LLM always return `pack_price`, but documents quote per tablet, per box or per ampoule, so that would have forced the LLM to do arithmetic, which is exactly where it fails silently. Stated-only extraction also lets the evidence check verify every number against the source.
